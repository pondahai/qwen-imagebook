## 執行方式

每頁一筆（每張間隔 3 秒送出，避免 API 阻塞）：

```
python api/api_script.py 1  "P1 的 prompt 內容"
python api/api_script.py 2  "P2 的 prompt 內容"
...（42 頁）
```

檔名沿用 `page{N}` 前綴。新圖與舊圖同在 `generated/`，挑定後再替換。

## 注意事項

- seed 固定在模板的 1234；同頁重生成結果會一樣，不滿意某張就改 seed（要我改說一聲）。
- 建議先跑 2-3 頁試水溫（例如 P1、P18、P42），確認角色外貌與色調對了再批量。
- 驗收重點：
  - P18 有沒有畫到媽媽、爸爸、小芽三人
  - P33 暖光有沒有從敵軍體內透出
  - P39 老燈是不是「小餘燼」而不是大團光
  - P42 那盞光是不是人形
  - 全書小滿：黑短髮＋橘紅外套是否一致
