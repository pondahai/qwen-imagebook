## 故事地基（已確認的決策）

| 項目 | 決策 |
|---|---|
| 目標讀者 | 8-12 歲兒童青少年 |
| 塔的真實目的 | **記憶方舟**：保存人類的記憶，為未來做準備 |
| 塔為何現在升起 | **舊敵逼近**：守護者啟動方舟作最後防線 |
| 敵人 | **蝕（吞噬者）**：吃記憶與光的實體，守護者的舊敵 |
| 主角 | 林小滿，普通家庭的孩子，父母＋妹妹 |
| 融合規則 | 老燈太古老、忘了「做人是什麼感覺」，方舟需要一顆人心。小滿自願進核心，成為方舟的「心」 |
| 守護者狀態 | 光在衰弱，這是最後一戰 |
| 決戰引擎 | 吞噬者吃記憶，但消化不了「想記住的意志」——小滿把妹妹的笑聲、家的溫暖丟進它身體，它吃不下愛 |
| 老守護者下場 | 沉睡在塔最深處，沒死；小滿偶爾在夢裡聽見它的聲音 |
| 少年肉身體 | 書中不解釋（能量體＝小滿，讀者自覺接受） |
| 結局 | 苦樂參半＋錨點：小滿成為新守護，每天傍晚在妹妹窗戶亮一盞光；書尾一句輕暗示（蝕的殘光未散盡） |

- 場景：俯瞰角度，巨物塔全景，城市遠景

**P3 所有人的手機**

**P4 那杯熱牛奶**
